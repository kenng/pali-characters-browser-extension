在网页的任何地方轻松输入巴利语（Pāli）发音符号——无需频繁寻找字符选择器，也不必切换键盘输入法。

**Pāli Easy Keyboard & Shortcut** 让你能够通过快捷键、可选的 ITRANS 拼音序列，或固定助手面板的一键插入功能，快速输入 ā、ī、ū、ñ、ṅ、ṃ、ṁ、ḍ、ḷ、ṇ、ṭ 和 ŋ。

非常适合学生、译者、学者以及任何需要在浏览器、表单、文档和在线编辑器中撰写巴利文的人士。

**功能特点**

• 覆盖所有常用巴利语字符的键盘快捷键
• 可选的 ITRANS 模式 —— 输入 aa → ā, ;n → ṅ, ;m → ṁ 等
• 适用于文本框、文本域（textarea）以及富文本编辑区域（contenteditable）
• 快捷插入字符栏与可点击的快捷键指南
• 可将拖拽式助手弹窗固定在页面上，方便边看边写
• 禅定编辑器（Zen Editor）—— 从弹出菜单打开的专注写作页面
• 可设置为在所有页面默认开启，或仅针对当前标签页启用
• 对 Windows 和 macOS 布局均友好的快捷键设计

**使用说明**

1. 安装扩展程序
2. 点击工具栏图标打开弹出菜单
3. 保持“启用”状态（推荐），或仅为当前页面开启
4. 光标定位到任意文本框并使用快捷键 —— 或打开快捷键指南点击字符直接插入
5. 可根据需要开启 ITRANS 模式，使用罗马化拼音序列输入
6. 需要无干扰写作环境时，可打开禅定编辑器（Zen Editor）

**支持的字符**

ā ī ū ñ ṅ ṃ ṁ ḍ ḷ ṇ ṭ ŋ
（以及适用的大写形式）

**适用人群**

• 在线做笔记的巴利语学习者与禅修者
• 处理三藏（Tipiṭaka）/ 经文文本的译者与编辑
• 撰写学术或研究资料的教师、学生和研究人员
• 厌倦了一次又一次复制粘贴发音符号的任何人

**ITRANS 拼音模式（启用时）**

在弹出菜单中启用 ITRANS 后，即可输入以下序列：

aa → ā
ii → ī
uu → ū
~n → ñ
;n → ṅ
.n → ṇ
.t → ṭ
.d → ḍ
.l → ḷ
.m → ṃ
;m → ṁ
.g → ŋ

大写字母序列将生成对应的大写字符（例如：AA → Ā）。

小提示：打开弹出菜单 → 点击“显示键盘快捷键”（或固定助手面板），即可一目了然地查看所有快捷键映射。
